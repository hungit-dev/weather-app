# weather-app

🌦️ Weather App
This is a simple weather app made with HTML, CSS, and JavaScript. You can search for any city to get the current temperature, how it feels, and see a matching background image based on how hot or cold the weather is.

🔍 Features
🏙️ Search for weather by city

🌡️ Shows:

Temp: xx°F

Feels like: xx°F

Location name

🖼️ Background changes based on temperature:

🔥 Hot (≥ 77°F)

🌤️ Warm (59°F to 76°F)

❄️ Cold (< 59°F)
